Windows settings are scattered all over the place. In Windows 10, the Start Menu search function does a pretty good job of finding settings by keyword, but it wasn’t always like this.

“God Mode” was built for Windows 7, but still available today. To create a shortcut to “God Mode”, which puts all kinds of settings into a single window, create a new folder on your desktop and name it to exactly this:

`GodMode.{ED7BA470-8E54-465E-825C-99712043E01C}`

Then just open it and see links to many different settings.
